### Nobody has to follow you.
*Personne n'est obligé de te suivre.*

**Influchanger** is a book, a manifesto and a set of tools for agile coaches and change agents who want to move things forward without imposing them, borrowing from six professions that know how to convince.

🌐 [influchanger.com](https://influchanger.com) · ✍️ [Sign the manifesto](https://influchanger.com/manifesto/) · 🟢 [status.influchanger.com](https://status.influchanger.com)

Most of the work lives in private repositories. The book is in progress, in French first, then in English.
